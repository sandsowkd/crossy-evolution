How the values were calculated

The average includes each chicken once on each of the eight maps. The best score is the largest score attained by any chicken on any map. Replays run until death with the existing ten-second no-progress eagle rule and no time limit. The same frozen networks, observation inputs and simulation code drive the explorer and this audit.

The map panel was fixed before the audit and taken from pre-existing recorded map seeds. It was not chosen for a smooth score curve. Each CSV row retains the source run, source generation and complete population size. This is a curated presentation sequence, not evidence of one uninterrupted 150-generation training run.
